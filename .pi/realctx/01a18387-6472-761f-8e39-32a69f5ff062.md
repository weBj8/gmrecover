Save capture (AD2 CopyEntTable/CopyConstraintTable, PreEntityCopy hooks, EntityMods, Wire/ACF data) must run in Lua on the main thread: these are Lua tables/functions, and rsgdll only touches Lua on the main thread (rsgdll has no engine entity/physics API). Only compress/CRC/IO runs on Rust workers. Past hang causes in lua/autorun/server/gmrecover.lua: contraption() calling constraint.GetAllConstrainedEntities per entity (O(n^2), fixed with con_seen), and copying whole moving contraptions in one tick (fixed: read poses in one tick, copy across ticks, apply_pose rewrites PhysicsObjects).
