gmrecover (rsgdll gmod module) cross builds: `RUSTFLAGS= cargo zigbuild --release --target {i686,x86_64}-unknown-linux-gnu.2.17` and `RUSTFLAGS= XWIN_ARCH=x86,x86_64 cargo xwin build --release --target {i686,x86_64}-pc-windows-msvc`; rename output to gmsv_gmrecover_<linux|linux64|win32|win64>.dll. RUSTFLAGS must be empty (global mold flags break cross linkers). Crate needs `client`/`menu` features declared because rsgdll macros emit cfgs for them. Lua-side `undefined-global` lint warnings are GMod API globals, not bugs.
