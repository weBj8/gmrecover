## Local cross builds
gmrecover (rsgdll gmod module) cross builds:
- Linux: `RUSTFLAGS= cargo zigbuild --release --target {i686,x86_64}-unknown-linux-gnu.2.17`
- Windows: `RUSTFLAGS= XWIN_ARCH=x86,x86_64 cargo xwin build --release --target {i686,x86_64}-pc-windows-msvc`
- Rename output to `gmsv_gmrecover_<linux|linux64|win32|win64>.dll`.
- `RUSTFLAGS` must be empty (global mold flags break cross linkers).
- Crate needs `client`/`menu` features declared because rsgdll macros emit cfgs for them.
- Lua-side `undefined-global` lint warnings are GMod API globals, not bugs.

## CI (.github/workflows/build.yml)
On the ubuntu-24.04 runner, cargo-xwin Windows jobs fail without LLVM setup:
- cc-rs (zstd-sys) needs `llvm-lib` on PATH.
- i686 link needs lld-link >= 19 (older versions fail with `invalid /export: _gmod13_close,EXPORTAS,...`).
- Fix: apt install `llvm-20 lld-20 clang-20`, and add `/usr/lib/llvm-20/bin` to `$GITHUB_PATH`.
- Overriding `CARGO_TARGET_*_LINKER` doesn't work; xwin forces `-C linker=lld-link`.
